# PyTorch Study

PyTorch 공식 튜토리얼과 실습 프로젝트를 기반으로 기초 개념과 컴퓨터비전 모델 학습 흐름을 정리하는 저장소입니다.

## 학습 목표

- PyTorch 기본 문법 이해
- Tensor, Dataset, DataLoader, Transform 개념 정리
- 딥러닝 모델 학습 흐름 이해
- 이미지 분류 프로젝트를 통한 컴퓨터비전 기초 다지기
- 실험 결과를 GitHub에 정리하는 습관 만들기

## 학습 순서

1. Tensor
2. Dataset & DataLoader
3. Transform
4. FashionMNIST MLP Classifier
5. CIFAR-10 CNN Classifier
